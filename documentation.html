SolarSaver Template Documentation

Thank you for purchasing SolarSaver. This guide will help you get your new landing page up and running in minutes.

1. Prerequisites

  • Node.js: Version 18.17 or higher (Required for Next.js 15).
  • Terminal: Basic command line knowledge.

2. Installation

Unzip the SolarSaver-Source.zip file and open your terminal in that folder.

# Install dependencies
npm install

3. Running Locally

Start the development server to see your changes correctly:

npm run dev

Open http://localhost:3000 in your browser.

4. Customization

Changing Text & Images

Most content is located in the app/page.tsx file or broken down into components in components/sections/.

Colors & Styling

We use Tailwind CSS v4. Global styles and CSS variables are located in app/globals.css.

SEO Note: Remember to update app/sitemap.ts and app/manifest.ts with your actual domain name before deploying.

5. Deployment

This project is optimized for deployment on Vercel or similar platforms.

npm run build
npm start
